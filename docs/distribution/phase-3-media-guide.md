## Citation Guidance for Journalists

When citing research from thenitishkr.in:

```
Nitish Kumar (@thenitishkr). "[Page Title]." thenitishkr.in, [Date]. [URL]
```

Example:
```
Nitish Kumar (@thenitishkr). "Article 12 and Digital Governance: How the Citizen Became Invisible." thenitishkr.in, 2026-06-14. https://thenitishkr.in/article-12/
```

Downloadable BibTeX, RIS, and plain-text citations are available on each research page and at `/citations/`.

## Evidence Classification for Media

When referencing case file claims, journalists should note the evidence classification:

| Label | Meaning | Can Be Cited As |
|---|---|---|
| Official Record | Court order, RTI reply, audit report | Primary source |
| Corroborated Record | 2+ independent primary sources | Corroborated primary source |
| Documented Allegation | Formally on record, not adjudicated | Allegation on record |
| DISHA Assessment | Analytical inference from records | Secondary analysis |
| Unresolved Question | No documented answer yet | Open question |

## What Not to Do

- ❌ Describe "press release sent to" as media coverage
- ❌ Invent journalist endorsements
- ❌ Use fake institutional logos, court seals, or government emblems
- ❌ Make unsupported claims about judicial recognition
- ❌ Claim "first in the world" status without verification
- ❌ Auto-publish press-note templates without review
