Source register

Research Source Register and Evidence Inventory

This page is the public starting point for source-linked research material. It records and points readers to document collections, evidence files, and source registers — not machine‑readable CSV or JSON datasets — while keeping manual verification requirements visible.

Primary register

EVIDENCE-INVENTORY.md lists currently mapped source files, issuing-authority fields, page usage and manual review status. It is a working register, not a claim that every document has already been fully verified.

Selected source files

  • DISHA whitepaper
  • Redacted writ petition record
  • Digital arrest root-cause record
  • Forensic intelligence report

Verification policy

Before a source is treated as complete, the archive should identify issuing authority, date, reference number, page or paragraph location, redaction status and how the source is used on the page.
