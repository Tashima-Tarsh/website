## 1. Search Intent Framework

Each query category maps to a distinct search intent. The site must match the intent, not just the keyword.

### Intent Classification

| Intent Type | What the User Wants | Site Page Should Provide |
|---|---|---|
| **Know** (informational) | Understand a concept or topic | Definition, framework, analysis |
| **Do** (transactional/action) | Complete an action or task | Checklist, template, step-by-step guide |
| **Evidence** (research) | Verify a claim or find a primary source | Source document, citation, record |
| **Navigate** (navigational) | Reach a specific person or site | Authoritative profile page |
| **Question** (answer-seeking) | Direct answer to a specific question | Concise answer + supporting detail |
| **Current** (news/temporal) | Latest development on a topic | News analysis, court update |
