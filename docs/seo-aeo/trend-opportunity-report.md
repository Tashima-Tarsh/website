## 1. Trend Relevance Filter

A trending topic may be recommended only when ALL of:

1. It is directly related to the site's established research subjects
2. The site has original evidence or analysis to contribute
3. The topic can be sourced reliably (primary documents, court records, official publications)
4. The page would remain useful after the immediate trend passes
5. The content can be maintained
6. Publication would not misrepresent legal or factual status

Rejected trends include: celebrity-driven, sensational, unsupported, outside site expertise, copied news, thin pages, traffic-capture pages.

## 3. Trend Opportunity Scoring Framework

For candidate topics identified through Google Trends or owner observation, score using:

| Factor | Weight | Scoring Method |
|---|---|---|
| Topical relevance | High | 0 (none) to 5 (core site subject) |
| Existing site authority | High | 0 (no related content) to 5 (dedicated section) |
| Current search interest | Medium | 0 (no interest) to 5 (breaking/peak) |
| Trend direction | Medium | -2 (declining) to +2 (rising steeply) |
| Evergreen value | High | 0 (hours) to 5 (years/permanent) |
| Evidence availability | Mandatory | 0 (none) to 5 (primary sources at hand) |
| Original contribution | Mandatory | 0 (nothing new) to 5 (unique evidence/analysis) |
| Competition type | Low | Inverted: 5 (no competition) to 0 (government/news dominance) |
| Maintenance burden | Low | Inverted: 5 (one-time) to 0 (daily updates needed) |
| Legal/editorial risk | Gate | Inverted: 0 (high risk) to 5 (no risk) |
| Internal-link fit | Low | 0 (no connecting pages) to 5 (fits existing hub) |
| Citation value | Medium | 0 (unlikely to be cited) to 5 (strong citation potential) |

**Minimum threshold for publication:** Must score ≥ 3 on both "Evidence availability" AND "Original contribution."
No score is final without documented method.
